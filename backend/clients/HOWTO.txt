Добавление клиента (нового сайта / виджета)
==========================================

1) Скопируйте папку `_template` в имя латиницей без пробелов, например: `myshop`.
   Исключение: папка `dart-art` соответствует agentId `default` (ваш сайт D-Art).

2) В новой папке отредактируйте:
   - system.md   — роль, стиль, правила ответа
   - contacts.json — phone и telegram (попадут в промпт блоком «официальные контакты»)
   - knowledge.json — факты о продукте (опционально)
   - meta.json     — поле name для отображения в БД

3) На сайте клиента в виджете укажите:
   data-agent-id="myshop"
   (для D-Art оставьте default или не указывайте)

4) Перезапустите бекенд (pm2/systemd), чтобы подтянуть изменения в SQLite.
   Либо первый запрос сам создаст агента из папки (ленивая регистрация).

5) В .env на сервере добавьте домен клиента в CORS_ORIGIN (через запятую).

6) Узнать chat_id для notify.json: попросите клиента написать /start боту уведомлений (тот же токен, что TELEGRAM_NOTIFY_BOT_TOKEN), если крутится мини-бот agent_system/notify-id-helper — он сам покажет id. Либо вручную через @userinfobot.

7) Кому в Telegram уходят лиды с этого агента:
   — скопируйте notify.json.example в notify.json и укажите telegramChatId (id после /start у бота уведомлений),
   — или в .env: TELEGRAM_NOTIFY_BY_AGENT={"123okna":"id","default":"ваш_id"}
   Бот один (TELEGRAM_NOTIFY_BOT_TOKEN), чаты разные.

Опционально: CLIENT_PROMPTS_HOT_RELOAD=1 — system prompt читается с диска при каждом сообщении (удобно для отладки, лишний I/O в проде).
